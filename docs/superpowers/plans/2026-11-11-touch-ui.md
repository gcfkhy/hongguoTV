# 手机 / 平板触摸界面 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 手机和平板获得触摸优先、短剧 App 风格的全新界面（首页竖滑推荐流、底栏/侧栏导航、触摸播放器），电视端保持不变。

**Architecture:** 新增 `touch/` 界面层（`TouchShell` + 各页面 + `TouchSheet` 弹层），通过窄接口 `TouchHost` 复用 `MainActivity` 里的数据与播放引擎。`MainActivity` 只在 `showCatalog / openDetail·showDetail / playEpisode` 入口按 `DeviceUi.touchFirst()` 分流，电视分支原样保留；上两次提交留下的触摸补丁在最后一个任务统一删除。

**Tech Stack:** Kotlin、Android 原生 View（无 Compose / RecyclerView，不新增依赖）、Media3 ExoPlayer 1.8.0、JUnit4 + Robolectric 4.14.1。

**Spec:** `docs/superpowers/specs/2026-11-11-touch-ui-design.md`

## Global Constraints

- 不新增任何第三方依赖；`minSdk = 21`，`compileSdk = 36`；Java/Kotlin 17。
- 电视判定仍是 `DeviceUi.television(context)`（`UI_MODE_TYPE_TELEVISION`），优先于窗口分级；电视代码路径与现有电视测试不得改变行为。
- 窗口分级按**窗口宽度 dp**：Compact `< 600`，Medium `600..840`（含 840），Expanded `> 840`。网格列数：Compact 3、Medium 4、Expanded 5（宽度 `< 1200dp`）或 6（`>= 1200dp`）。Compact 用底部导航栏（56dp），Medium/Expanded 用左侧窄栏（80dp）。
- 触摸目标 `>= 48dp`；字号：正文 15sp、次要 13sp、最小 12sp，尊重系统字体缩放；页面水平边距 Compact 16dp / 其他 24dp；卡片间距 12dp；卡片圆角 12dp，弹层圆角 20dp。强调色沿用 `TvStyle.accent`（`#FF7844`），背景沿用 `TvStyle.background`。
- 弹层：Compact 为底部弹层；Medium/Expanded 为居中卡片，最大宽度 480dp；点遮罩和系统返回都会关闭。
- 屏幕方向：触摸设备 `SCREEN_ORIENTATION_FULL_SENSOR`，电视仍 `SENSOR_LANDSCAPE`；`AndroidManifest.xml` 已声明 `configChanges`（含 `orientation|screenSize|screenLayout|uiMode`），Activity 不重建。
- 播放器控件 3 秒无操作自动隐藏；长按画面 2 倍速，松开恢复原速；垂直滑动换集沿用 `PlaybackInput.verticalFlingDelta`。
- 所有可点击的触摸视图设置 `contentDescription`。
- 文案：触摸界面不得出现"方向键""确定""遥控器"字样。
- 工作区里已有与本任务无关的未提交改动（`kotlin-tv/decoder-ffmpeg/build.gradle.kts`、`kotlin-tv/decoder-ffmpeg/tools/build_native.py`、仓库根目录两个无名文件）：**不得触碰**，每次提交只 `git add` 本任务列出的路径。
- 提交信息按各任务里给出的原文，不额外添加署名行。
- 全部命令从仓库根目录 `E:\资料\Project\Self\hongguoTV` 运行；Gradle 为 `./kotlin-tv/gradlew -p kotlin-tv ...`。Robolectric 需要联网下载依赖（`build.gradle.kts` 已配置 Maven Central 镜像地址）。

## Review Focus

1. **播放中旋转**：竖屏↔横屏转动时不得重新准备播放，位置和播放/暂停状态保持（今天的 `MainActivity.onConfigurationChanged` 会调用 `playEpisode` 重载）→ Task 11。
2. **系统栏/刘海/手势条**：底栏、播放控件、弹层按钮不得被状态栏、刘海或手势条遮挡 → Task 5、11。
3. **返回键逐层回退**：弹层打开时先关弹层；搜索态先退出搜索；详情→相关作品→详情按旧路径回退；非首页顶层按返回回到首页，首页按返回退出 → Task 3、5、7、9。
4. **空、失败、离线状态**：无收藏、无历史、搜索无结果、断网、榜单加载失败都必须显示明确文案和重试/去找剧按钮，不能白屏 → Task 6、7、8。
5. **极端内容**：超长剧名、系统字体放大到 1.3 倍、窗口宽 320dp 时文字不得截断到不可读、按钮不得溢出屏幕 → Task 2、6、9。
